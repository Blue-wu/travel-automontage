# 旅行 Vlog 节奏规范

> Agent 在 `storyboard` 和 `edit_decision` 阶段必须遵守的剪辑节奏准则。
> 节奏是旅行 Vlog 的呼吸——没有节奏变化的视频会让观众感到疲倦。

## 1. 动静结合原则

### 1.1 核心法则

**每个 10 秒片段内必须有"静→动"或"动→静"的转换。**

| 类型 | 定义 | 示例 |
|---|---|---|
| 静 | 固定机位/缓慢推镜/风景空镜 | 富士山全景、寺庙柱廊 |
| 动 | 手持跟拍/快速摇移/人物动作 | 街头行走、美食制作、车窗外 |

### 1.2 禁止模式

- 连续 3 个"静"镜头 → 观众无聊划走
- 连续 3 个"动"镜头 → 观众视觉疲劳
- 唯一例外：高潮段的快速混剪可以连续"动"，但不超过 5 秒

## 2. 景别嵌套规范

### 2.1 景别定义

| 景别 | 缩写 | 画面范围 |
|---|---|---|
| 大远景 | ELS | 航拍/超广角，展示整体环境 |
| 远景 | LS | 全身+环境 |
| 中景 | MS | 腰部以上 |
| 近景 | CU | 胸部以上/物体特写 |
| 大特写 | ECU | 极致局部（眼睛、纹理） |

### 2.2 景别切换规则

**航拍大景之后必须接地面人文细节（景别嵌套）：**

```
ELS（航拍富士山） → CU（路边小吃摊热气） → LS（街道全景）
```

**禁止相邻两个镜头同景别**，除非是快剪段落（每镜 <1.5s）。

### 2.3 推荐景别序列

```
ELS → MS → CU → LS → MS → ECU → ELS
```

这种"远→近→远→近"的嵌套创造了视觉呼吸感。

## 3. 黄金时间轴

### 3.1 30 秒旅行 Vlog

| 时间 | 内容 | 景别 | 节奏 | 说明 |
|---|---|---|---|---|
| 0-3s | 钩子 + 最具冲击力画面 | ELS | 静 | 航拍日出/天际线/震撼景观 |
| 3-8s | 第一转场，引入目的地 | LS | 静→动 | 字幕打出目的地名称 |
| 8-15s | 街头美食/人文特写 | CU/MS | 动（快剪） | 每镜 1-2 秒，建立烟火气 |
| 15-22s | 交通转移，"在路上" | LS/MS | 动 | 新干线/自驾/步行跟拍 |
| 22-28s | 高潮景观 + 情绪抒发 | ELS | 静 | 最美画面，音乐高潮 |
| 28-30s | "终"字淡出 + CTA | MS | 静 | 简洁收尾 |

### 3.2 15 秒旅行短视频

| 时间 | 内容 | 镜头数 | 说明 |
|---|---|---|---|
| 0-3s | 钩子画面 | 1-2 | 最强冲击力 |
| 3-10s | 快速信息输出 | 4-5 | 每镜 1.5s，高密度 |
| 10-13s | 反转/高潮 | 1-2 | 最美画面 |
| 13-15s | CTA | 1 | 引导互动 |

### 3.3 60 秒旅行 Vlog

| 时间 | 内容 | 节奏 |
|---|---|---|
| 0-3s | 钩子 | 静 |
| 3-10s | 目的地建立 | 静→动 |
| 10-20s | 人文探索（美食/街景） | 动（快剪） |
| 20-30s | 风景大景 | 静 |
| 30-40s | 体验/活动（潜水/滑雪/徒步） | 动 |
| 40-50s | 高潮画面 + 音乐 chorus | 静→动 |
| 50-58s | 情绪收束 | 静 |
| 58-60s | CTA 淡出 | 静 |

## 4. 剪辑密度曲线

### 4.1 密度定义

剪辑密度 = 每分钟镜头数量（cpm = cuts per minute）。

### 4.2 推荐密度曲线（30秒版）

```
cpm
40 |         ██                              ██
30 |       ██  ██          ██              ██  ██
20 |     ██      ██      ██  ██          ██      ██
10 |   ██          ██  ██      ██      ██          ██
 0 | ██                          ██  ██              ██
   +--+--+--+--+--+--+--+--+--+--+--+--+--+--+--+--→ 秒
     0     5    10    15    20    25    30
```

- 0-3s：高密度（钩子要快，2-3 个镜头）
- 3-15s：中密度（展开叙事，每镜 1.5-2 秒）
- 15-22s：低密度（交通/转场，每镜 3-4 秒）
- 22-28s：高密度（高潮快剪，每镜 1-1.5 秒）
- 28-30s：极低密度（收尾，1 个镜头）

### 4.3 参考案例

爆款埃及旅行短片的节奏：
```
开篇静（航拍日出）→ 动（船夫拉帆）→ 静（神庙石柱）
→ 动（老街集市）→ 静（沙漠全景）→ 动（骑马越野）
→ 静（日落阳台）
```
形成完美的呼吸感。

## 5. 转场规范

### 5.1 转场类型选择

| 转场 | 适用场景 | 使用频率限制 |
|---|---|---|
| 硬切 | 最常用，适合快节奏 | 不限 |
| 叠化 | 时间流逝/情绪转换 | 每视频 ≤3 次 |
| 淡入淡出 | 段落分隔/开场结尾 | 每视频 ≤2 次 |
| 推拉 | 强调/聚焦 | 每视频 ≤2 次 |
| 擦除 | 禁止使用 | 0 次 |

### 5.2 转场规则

- 一个视频最多使用 2-3 种转场类型
- 相邻两个镜头禁止使用相同转场（除硬切外）
- 钩子幕（0-3s）只用硬切，不用其他转场
- 高潮段可以连续硬切制造紧迫感

## 6. 音画同步规则

### 6.1 Beat Sync

- 镜头切换点尽量卡在 BGM 的 beat 上
- 至少 60% 的切换点要卡在 beat ±100ms 内
- 钩子幕结束点（3s）必须卡在第一个重音
- 高潮段每个镜头都卡 beat

### 6.2 情绪同步

| BGM 段落 | 画面对应 |
|---|---|
| Intro（前奏） | 钩子画面 |
| Verse（主歌） | 展开/叙事 |
| Chorus（副歌） | 高潮/最美画面 |
| Bridge（桥段） | 转场/交通 |
| Outro（尾奏） | 收尾/CTA |

## 7. 幻灯片风险规避

**"假视频" = 静态图片轮播加 BGM，完播率极低，算法会降权。**

### 规避规则

- 每个镜头必须有画面内运动（人物移动/镜头移动/物体变化）
- 连续 2 个纯静态镜头即触发 slideshow_risk
- 如果素材确实没有动态画面，必须加入 Ken Burns 效果（缓慢缩放/平移）
- Ken Burns 效果的移动速度：每秒移动画面宽度的 2-5%
