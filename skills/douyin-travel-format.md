# 抖音旅行赛道格式要求

> Agent 在 `qa` 阶段必须执行的抖音平台合规检查清单。
> 不符合以下任何一条，视频将被算法降权或无法发布。

## 1. 视频格式硬性要求

### 1.1 分辨率与宽高比

| 参数 | 要求 | 检查方法 |
|---|---|---|
| 宽高比 | 9:16（竖屏）| ffprobe 检查 width/height 比例 |
| 分辨率 | ≥ 1080×1920 | ffprobe 检查 |
| 帧率 | 30fps 或 60fps | ffprobe 检查 |
| 编码 | H.264 或 H.265 | ffprobe 检查 codec |

### 1.2 时长要求

| 类型 | 时长范围 | 备注 |
|---|---|---|
| 旅行短视频 | 15-20s | 极短高密度 |
| 旅行 Vlog | 25-45s | 完播率最优区间 |
| 旅行混剪 | 30-60s | 不超过 60s |
| 旅行长视频 | 60-180s | 仅限已开通长视频权限 |

**禁止超过 60s**（除非已开通长视频权限）。

### 1.3 文件大小

- 单视频 ≤ 500MB
- 比特率建议：1080p → 8-12 Mbps

## 2. 内容合规检查

### 2.1 字幕要求

- **必须有字幕** — 抖音 60%+ 用户静音浏览
- 字幕字体大小 ≥ 画面高度的 3%
- 字幕位置：中下 1/3 区域
- 字幕颜色与背景要有足够对比度（WCAG AA 标准）
- 关键字幕停留 ≥ 1.5 秒

### 2.2 音频要求

| 参数 | 要求 | 检查方法 |
|---|---|---|
| 音轨 | 必须有音频轨 | ffprobe |
| 音量 | -14 LUFS ~ -10 LUFS | ffmpeg loudnorm 检测 |
| 峰值 | ≤ -1 dBTP | ffmpeg ebur128 |
| 底噪 | ≤ -60 dB | ffprobe |

### 2.3 画面质量

- 无黑帧（连续黑屏 > 0.5s 即不合格）
- 无绿屏/花屏
- 无水印（其他平台 logo、剪辑软件水印）
- 画面稳定度：抖动指数 < 5（可用 vidstab 检测）

## 3. 抖音旅行赛道内容规范

### 3.1 标题/文案规范

- 标题 15-20 字最优
- 包含目的地关键词
- 包含 1-2 个热门话题标签（#旅行 #目的地名）
- 禁止诱导性标题（"不看后悔"、"震惊"等）

### 3.2 封面要求

- 封面必须是视频中最具冲击力的一帧
- 封面文字 ≤ 10 字
- 封面文字位置在画面上 1/3

### 3.3 互动引导

- 视频结尾 1-2 秒有 CTA（点赞/收藏/评论引导）
- CTA 用画面文字而非口播
- 禁止"关注我了解更多"等泛泛 CTA，要具体："收藏这份东京美食地图"

## 4. 算法友好性检查

### 4.1 完播率优化

- 前 3 秒必须有画面变化（不能是同一个静止画面）
- 前 3 秗必须引起好奇或冲击
- 全程无超过 3 秒的静止画面
- 结尾不超过 1 秒黑屏

### 4.2 互动率优化

- 视频中至少出现 1 次文字提问（"你最想去哪个？"）
- 视频中有可截图保存的信息（攻略/地图/清单）
- 结尾 CTA 引导评论而非仅点赞

### 4.3 幻灯片风险检测

抖音算法会检测"伪视频"（静态图片轮播）：

| 指标 | 阈值 | 检测方法 |
|---|---|---|
| 连续静态帧 | ≤ 2 帧 | 场景变化检测 |
| 帧间差异 | ≥ 0.02 | MSE/SSIM 计算 |
| Ken Burns 补偿 | 可接受 | 检测是否有缓慢缩放/平移 |

## 5. 质检 Gate 清单

QA 阶段必须执行以下 gate，全部通过才可输出：

| Gate | 检查内容 | 通过条件 |
|---|---|---|
| `douyin_format_check` | 9:16, 1080p, ≤60s, H.264/H.265 | 全部满足 |
| `audio_level_check` | 音量 -14 ~ -10 LUFS, 峰值 ≤ -1 dBTP | 全部满足 |
| `subtitle_presence_check` | 视频中存在字幕 | 至少有 1 段字幕 |
| `slideshow_risk_check` | 幻灯片风险评分 | ≤ 0.3 |
| `black_frame_check` | 无连续黑帧 | 无 > 0.5s 黑帧 |
| `pacing_curve_check` | 动静节奏曲线 | 10s 内有动静转换 |
| `watermark_check` | 无第三方水印 | 检测通过 |

## 6. 不通过时的修复策略

| 未通过 Gate | 修复方式 |
|---|---|
| douyin_format_check | 重新渲染为 9:16 1080p |
| audio_level_check | ffmpeg loudnorm 重新归一化 |
| subtitle_presence_check | 回到 edit_decision 加字幕 |
| slideshow_risk_check | 加入 Ken Burns 效果或替换素材 |
| black_frame_check | 裁剪黑帧段 |
| pacing_curve_check | 回到 edit_decision 调整节奏 |
| watermark_check | 裁剪或模糊水印区域 |
