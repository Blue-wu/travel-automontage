# 旅行 Vlog 画面字幕规范

> 用于 `copywriting` stage。本文件会被拼进 LLM 的 system prompt，
> 不是给人看的说明书，是给模型的判据。
>
> 适用对象：**卡在画面上的字幕**（3-10 字），不是口播稿。
> 口播那套规则（称呼"姐妹家人们"、emoji、话题标签、结尾 CTA）在这里**不适用**。

---

## 1. 唯一核心判据：替换测试

> **把句子里的地名换成任意另一个目的地。如果句子依然成立 —— 这是套话，删掉。**

| 句子 | 换成"云南"后 | 判定 |
|---|---|---|
| 在新疆找到与世界和解的答案 | 在云南找到与世界和解的答案 | ✗ 完全成立 → 套话 |
| 揣着新疆的晚风满载而归 | 揣着云南的晚风满载而归 | ✗ 完全成立 → 套话 |
| 人间值得 | 人间值得 | ✗ 连地名都不需要 → 重度套话 |
| **十点了，天还亮着** | 云南十点天早黑了 | ✓ 不成立 → 保留 |
| **五月底，湖还没化透** | 云南没有这回事 | ✓ 不成立 → 保留 |
| **导航说三小时，开了五个** | 云南距离没这么夸张 | ✓ 不成立 → 保留 |

**通过替换测试 = 有活人感。** 这条规则比任何抽象要求都有效，因为它可验证。

---

## 2. 禁用清单（直接来自旧模板池，已确认为套话）

以下词句**一律不得出现**，包括其近义变体：

```
人间值得        治愈瞬间        这就是远方      来了就懂了
什么都不想了    时间慢下来了    被治愈的一天    安静且自由
风知道答案      和自己和解了    路上才是答案    世界比想象中大
所有奔波都值了  整个人都麻了    一眼万年        梦里的样子
名不虚传        亲眼见到才懂    比想象中震撼    还会再来的
故事还很长      带着风景离开    说走就走        出发永远不晚
```

同时禁用这些**万能形容词**（信息量为零）：
`绝美 / 震撼 / 治愈 / 惊艳 / 宝藏 / 神仙 / 天花板 / 秒杀 / 无敌`

---

## 3. 活人感的四个来源

写不出具体的句子，通常是因为没用上这四类原料。

### 3.1 时间的具体性
不是"清晨""黄昏"，是**只有当时当地才有的时间事实**。
- ✓ `十点了，天还亮着`（新疆时差，北京时间 22:00 才黑）
- ✓ `五点半的太阳`
- ✗ `美好的清晨`

### 3.2 数字与落差
具体数字自带可信度，落差自带情绪。
- ✓ `导航说三小时，开了五个`
- ✓ `白天二十度，夜里穿羽绒`
- ✓ `第三次来才等到`
- ✗ `路途遥远`

### 3.3 意外与不完美
**顺利的旅程没有故事。** 计划外的事才是记忆点。
- ✓ `独库还没开`（5 月底封路）
- ✓ `这段路没信号`
- ✓ `风大到关不上车门`
- ✓ `等了四十分钟，云没散`
- ✗ `一切都很顺利`

### 3.4 身体感受
视觉是所有人共有的，**体感是私人的**。
- ✓ `冻手`
- ✓ `嘴唇裂了`
- ✓ `耳朵嗡嗡的`（海拔）
- ✗ `心旷神怡`

## 4. 字数硬约束（按镜头时长）

字幕停留时间 = 镜头时长。读不完等于没有。

| 镜头时长 | 字幕上限 | 说明 |
|---|---|---|
| < 1.5s | **0 字** | 快剪段不上字幕，上了也看不清 |
| 1.5–2.5s | ≤ 6 字 | |
| 2.5–4s | ≤ 10 字 | 主力区间 |
| > 4s | ≤ 14 字，或拆两行 | |

**整条片子的字幕覆盖率控制在 40–60%。** 每个镜头都有字 = 廉价感。
留白的镜头让有字的镜头更重。

---

## 5. 时间线级规则（不可逐镜头独立生成）

这是"故事性"的唯一来源。**必须一次性生成整条片子的全部字幕**，
看到完整时间线后再决定每一句写什么。

### 5.1 禁止时序矛盾
第 3 镜说"终于到了"、第 7 镜说"初见" —— 独立随机生成必然出这种错。
字幕的时间线必须单调：出发 → 在路上 → 抵达 → 深入 → 离开。

### 5.2 必须有一处呼应
开头埋的东西，结尾要回收。
```
0-3s   独库还没开
...
28s    明年六月再来
```
一条片子只需要**一组**呼应，多了刻意。

### 5.3 情绪不能平
15-20 条字幕里，至少要有：
- 1 条**具体的意外**（3.3 类）
- 1 条**身体感受**（3.4 类）
- 1 条**可截图的句子** —— 但它必须通过替换测试，否则就是金句套话

### 5.4 同一条片子内不重复句式
两条字幕都是"X 的 Y"结构 → 改掉一条。

---

## 6. 原料要求（对上游的硬依赖）

字幕质量的上限 = 素材描述质量。模型拿不到具体信息就只能写套话。

**必须提供给 copywriting stage：**

| 输入 | 用途 | 缺失后果 |
|---|---|---|
| `segment.summary`（具体的画面描述） | 写出画面里真实存在的东西 | 只能写通用词 |
| `shot_at` / EXIF 时间 | 3.1 类时间具体性 | 写不出"十点天还亮" |
| GPS / 地名 | 地点具体性 | 只能用大地名 |
| `duration_sec` | 卡字数 | 字幕读不完 |
| **`brief.trip_context`** | **3.2 / 3.3 类的唯一来源** | **必然退化成套话** |

> ⚠️ `visual_tags` 若是查表得来的通用词（"湖泊/湛蓝/倒影"），
> 对文案毫无价值。必须传 `summary` 级别的具体描述。

### brief.trip_context 是关键输入

用户提供的 1-3 句真实背景，例如：
```
第三次来新疆，前两次都没等到日照金山。这次五月底去的，
独库公路还没开，绕了果子沟。赛里木湖边上还有没化的冰。
```

**这段话是整条片子活人感的种子。** 没有它，模型再强也只能写出更好听的套话。

---

## 7. 输出格式

```json
{
  "subtitles": [
    {"order": 1, "text": "独库还没开", "reason": "开篇意外，埋呼应"},
    {"order": 2, "text": "", "reason": "快剪段留白"},
    {"order": 3, "text": "绕了两百公里", "reason": "数字落差"}
  ],
  "callback_pair": [1, 18],
  "self_check": {
    "substitution_test_passed": true,
    "banned_words_used": [],
    "coverage_rate": 0.52,
    "has_accident": true,
    "has_body_feeling": true
  }
}
```

**模型必须自行跑一遍替换测试**，任何一条不通过就重写该条。

## 8. 完整样例（few-shot，直接作为 prompt 示例使用）

### 8.1 输入 brief

> ⚠️ 下面的 `trip_context` 是**示例**。其中的事实（第几次来、独库是否开放、
> 湖面是否有冰）必须替换为创作者的真实经历 —— 写进片子的是事实陈述，编造即造假。

```yaml
destination: 新疆·伊犁环线
shot_at: 2026-05-27 ~ 05-31
persona: 克制、不煽情、像跟朋友讲事
trip_context: |
  五月底自驾伊犁环线。原计划走独库公路，到了才知道六月才开放，
  临时绕果子沟多跑了两百公里。赛里木湖边上还有没化完的冰。
  最不适应的是天黑得晚，北京时间十点太阳才下去，
  每天都拍到很晚，夜里冷得握不住相机。
avoid: [人间值得, 治愈, 说走就走, 绝美, 震撼]
```

### 8.2 输出：30 秒时间线（15 镜头，字幕覆盖率 47%）

| # | 时长 | 画面 | 字幕 | 依据 |
|---|---|---|---|---|
| 1 | 2.5s | 航拍果子沟盘山公路 | **独库还没开** | 3.3 意外·开篇埋呼应 |
| 2 | 1.5s | 车内前挡风山路 | — | <1.5s 快剪留白 |
| 3 | 2.0s | 公路远景 | **绕了两百公里** | 3.2 数字落差 |
| 4 | 1.5s | 车窗外掠过 | — | 留白 |
| 5 | 1.5s | 湖面推近 | — | 留白（把注意力让给下一镜） |
| 6 | 2.0s | 赛里木湖全景 | **五月底，湖还没化透** | 3.1 时间具体性 |
| 7 | 1.0s | 岸边残冰特写 | — | <1.5s 不上字 |
| 8 | 2.0s | 航拍草原河曲 | — | 留白 |
| 9 | 1.5s | 路边野花 | — | 留白 |
| 10 | 2.0s | 草原羊群 | **羊比车多** | 3.2 具体对比 |
| 11 | 1.5s | 牧民骑马经过 | — | 留白 |
| 12 | 2.5s | 日落·湖面 | **十点了，天还亮着** | 3.1 可截图句·通过替换测试 |
| 13 | 1.5s | 山脊线天光 | — | 留白 |
| 14 | 3.0s | 星空 | **冻手** | 3.4 身体感受 |
| 15 | 4.0s | 航拍拉远·公路 | **明年六月再来** | 5.2 回收第 1 镜呼应 |

### 8.3 同一条片子的套话版（旧模板池的实际产出）—— 用于对比

| # | 套话版 | 具体版 | 替换测试 |
|---|---|---|---|
| 1 | 人间值得 | 独库还没开 | 套话版换任何地名都成立 ✗ |
| 3 | 所有奔波都值了 | 绕了两百公里 | ✗ |
| 6 | 比想象中震撼 | 五月底，湖还没化透 | ✗ |
| 10 | 治愈瞬间 | 羊比车多 | ✗ |
| 12 | 时间慢下来了 | 十点了，天还亮着 | ✗ |
| 14 | 什么都不想了 | 冻手 | ✗ |
| 15 | 还会再来的 | 明年六月再来 | ✗ |

**关键差异不在文笔，在信息量。** 套话版 7 条字幕的信息量总和为 0 ——
删掉它们，观众对这趟旅行的了解不会减少分毫。
具体版每一条都在补充只有在场者才知道的事实。

## 9. trip_context 可半自动生成

不要让创作者从零写背景。**事实骨架可以从素材元数据自动重建**：

| 自动可得 | 来源 |
|---|---|
| 日期范围、每天的拍摄时段 | EXIF / `shot_at` |
| 路线序列、地名 | GPS 反查 |
| 每天拍了什么类型的场景 | `segment.scene_type` 按时间聚合 |
| 哪个地方停留最久、拍得最多 | 素材密度分布 |
| 最晚的一条素材是几点 | 时间戳最大值（"十点天还亮"就是这么得到的）|

**只有下面三件事必须由创作者提供**（问三个问题即可，不必写作文）：

1. 这趟**原计划**是什么？和实际有什么出入？ → 产出 3.3 类意外
2. 哪个瞬间**最不舒服**？（冷、累、堵、等） → 产出 3.4 类身体感受
3. 为什么去这一趟？ → 决定整片的情绪基调

> 前两个问题的答案几乎必然通过替换测试，因为不适和意外天然是私人的。
